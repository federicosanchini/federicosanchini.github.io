REPRODUCIBLE RESEARCH

Historical data. Explicit assumptions.

This app adapts the Python backtester in Federico Sanchini’s HL repository to run in the browser. All results use the uploaded repository’s historical CSV snapshot, not live market data.

Strategy and portfolio accounting

Daily signals select the highest scores for longs and the lowest for shorts. Each selected symbol receives a fixed-notional order. Same-side orders merge at a weighted-average entry price; opposite-side orders reduce, close, or flip the position. Long selections take precedence if the selections overlap. Actual fills can be fewer than requested.

Isolated mode locks collateral per symbol; funding changes that collateral. Cross mode shares account collateral. Leverage sets initial margin (notional ÷ leverage), not a multiplier on fixed-notional PnL. Orders above the repository’s asset leverage limit are skipped. Limits and maintenance rates are a historical, partial model table, not verified current exchange rules.

Execution, funding and liquidation

Orders use the configured UTC candle open, with a bounded entry delay. Funding is applied after orders at each hourly timestamp: −signed quantity × oracle price × funding rate. Positive rates cost longs and pay shorts. Missing funding records contribute no funding and are counted below; missing oracle prices use the latest available mark.

Candle closes proxy mark prices; lows and highs proxy intrahour liquidation triggers. Cross liquidation is a sequential portfolio approximation; the intrahour price path, exchange margin tiers, slippage, market impact and order-book liquidity are not modeled. Oracle fallback candles have identical OHLC values and can understate liquidation risk. Stale marks are carried when no permitted candle is available.

Changes from the original Python model

Collateral checks use the current candle open instead of its future close. Timed exits retain a reference to their original exposure so an old exit cannot close a newly reopened position. Risk-reducing exits are allowed even if free collateral is depleted; flips must fund the new exposure. Final closure uses the actual stop time if equity is depleted. Signal execution defaults to a one-day lag because precise historical publication times are absent. These changes can make results differ from the original script.

Metric definitions

Equity = initial capital + realized price PnL + unrealized price PnL + funding − fees. Daily returns use consecutive UTC day-end equity values, with initial capital as the first baseline. Sharpe uses mean daily excess return ÷ sample standard deviation × √365. Sortino uses the root-mean-square negative daily excess return as its denominator, across all days. The annual risk-free input is converted to a compound daily rate.

CAGR = (final equity ÷ initial capital)^(365 ÷ elapsed days) − 1. Short windows can produce extreme annualized values. Maximum drawdown uses hourly equity and includes initial capital as the starting peak. Calmar = CAGR ÷ absolute maximum drawdown. Undefined metrics display “—”; CAGR is undefined for nonpositive final equity.

Win rate and profit factor use closing-event price PnL minus exit fees. They exclude entry fees and funding, and partial closes count as separate events. They are not full round-trip net trade statistics. Full account performance includes every fee and funding payment.
